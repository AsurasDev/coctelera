**Branch**: `001-coctelera-brutalist-db` | **Date**: 2026-06-06

## Directus Collections

### `cocktails`

Primary collection. Each record is one cocktail recipe.

| Field               | Type            | Required | Notes |
|---------------------|-----------------|----------|-------|
| `id`                | uuid (PK)       | yes      | Auto-generated by Directus |
| `slug`              | string (unique) | yes      | URL-safe identifier, e.g. `negroni` |
| `name`              | string          | yes      | Display name, e.g. "Negroni" |
| `description`       | text            | yes      | Prose description, 1–3 sentences |
| `base_spirit`       | string          | yes      | e.g. "Ginebra", "Ron", "Tequila" |
| `category`          | string          | yes      | enum: Clásico, Tropical, Refrescante, Moderno, Aperitivo, Sour |
| `country`           | string          | yes      | e.g. "Italia", "Cuba", "México" |
| `temperature`       | string          | yes      | enum: Con hielo, Sin hielo, Frozen |
| `abv`               | decimal         | yes      | Alcohol by volume percentage, e.g. 24.5 |
| `preparation_time`  | integer         | yes      | Minutes, e.g. 4 |
| `difficulty`        | string          | yes      | enum: Fácil, Medio, Difícil |
| `glass_type`        | string          | yes      | enum: rocks, highball, coupe, martini, hurricane, wine, shot |
| `glass_label`       | string          | yes      | Human-readable, e.g. "Vaso bajo", "Copa coupe" |
| `garnish`           | string          | no       | e.g. "orange", "lime", "cherry", "mint" |
| `tone_color`        | string          | yes      | Panel color key: blue, teal, green, violet, orange, red, emerald, amber |
| `instructions`      | text            | yes      | Full preparation narrative (also split into steps) |
| `tags`              | json            | no       | Array of strings, e.g. ["IBA Cocktail", "Bitter"] |
| `status`            | string          | yes      | Directus: published, draft, archived |
| `sort`              | integer         | no       | Manual sort order |
| `date_created`      | timestamp       | auto     | |
| `date_updated`      | timestamp       | auto     | |

**Relationships**:
- `ingredients` → M2M via `cocktails_ingredients` junction table
- `images` → O2M via `cocktails_files` (Directus Files)
- `steps` → O2M via `cocktail_steps` (ordered preparation steps)

---

### `cocktail_ingredients` (junction / O2M)

Each row is one ingredient line for a cocktail.

| Field         | Type    | Required | Notes |
|---------------|---------|----------|-------|
| `id`          | integer | yes      | Auto |
| `cocktail_id` | uuid    | yes      | FK → cocktails.id |
| `name`        | string  | yes      | Ingredient name, e.g. "Ginebra" |
| `amount`      | string  | yes      | Display string, e.g. "30 ml", "2 cdtas", "Al gusto" |
| `sort`        | integer | yes      | Display order (1-indexed) |
| `optional`    | boolean | no       | Default false |
| `note`        | string  | no       | e.g. "preferiblemente London Dry" |

**Note**: Amount is stored as a display string (not split into numeric + unit) to support values like "Al gusto", "½ lima", "1 terrón".

---

### `cocktail_steps` (O2M)

Ordered preparation steps for a cocktail.

| Field         | Type    | Required | Notes |
|---------------|---------|----------|-------|
| `id`          | integer | yes      | Auto |
| `cocktail_id` | uuid    | yes      | FK → cocktails.id |
| `step_number` | integer | yes      | 1-indexed |
| `instruction` | text    | yes      | Single step instruction |

---

### `cocktail_images` (O2M via Directus Files)

| Field         | Type    | Required | Notes |
|---------------|---------|----------|-------|
| `id`          | integer | yes      | Auto |
| `cocktail_id` | uuid    | yes      | FK → cocktails.id |
| `directus_files_id` | uuid | yes   | FK → directus_files.id |
| `sort`        | integer | yes      | Display order |
| `copyright`   | string  | no       | Attribution, e.g. "Kitchen Swagger" |

## TypeScript Types (Frontend Build-Time)

These types are used in Astro build scripts and data-fetching utilities.

```typescript
// Fetched from Directus at build time
interface Cocktail {
  id: string;
  slug: string;
  name: string;
  description: string;
  base_spirit: string;
  category: string;
  country: string;
  temperature: 'Con hielo' | 'Sin hielo' | 'Frozen';
  abv: number;
  preparation_time: number;
  difficulty: 'Fácil' | 'Medio' | 'Difícil';
  glass_type: 'rocks' | 'highball' | 'coupe' | 'martini' | 'hurricane' | 'wine' | 'shot';
  glass_label: string;
  garnish?: string;
  tone_color: 'blue' | 'teal' | 'green' | 'violet' | 'orange' | 'red' | 'emerald' | 'amber';
  instructions: string;
  tags?: string[];
  ingredients: CocktailIngredient[];
  steps: CocktailStep[];
  images: CocktailImage[];
}

interface CocktailIngredient {
  id: number;
  name: string;
  amount: string;
  sort: number;
  optional: boolean;
  note?: string;
}

interface CocktailStep {
  id: number;
  step_number: number;
  instruction: string;
}

interface CocktailImage {
  id: number;
  directus_files_id: string;
  sort: number;
  copyright?: string;
}

// Derived at build time for gallery inlining
interface CocktailSummary {
  slug: string;
  name: string;
  base_spirit: string;
  category: string;
  country: string;
  temperature: string;
  abv: number;
  difficulty: string;
  glass_type: string;
  glass_label: string;
  garnish?: string;
  tone_color: string;
  imageUrl?: string;       // First image URL from Directus
}
```
